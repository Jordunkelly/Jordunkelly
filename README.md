### Active Projects

**MoMo** — A full-stack personal finance platform built from scratch as a native Windows desktop app using Electron + Next.js 15 + Prisma + TypeScript. Ingests real-time bank and credit card data via Gmail IMAP, runs a background cron sync engine, and renders a live cash flow forecast timeline, spend breakdown dashboard, weekly grocery tracker, and monthly scorecard with grade thresholds — all on a local SQLite database with zero cloud dependency.

Shipped as a one-click Windows installer built with Inno Setup, bundling automatic installation of Node.js, Git, and VS Code via winget, a first-run setup wizard for Gmail App Password auth and household configuration, Prisma database migrations, and a system tray app with a loading screen. The path to native packaging alone involved debugging PowerShell SFX failures, ps2exe execution policy blocks, 7-Zip symlink permission errors, Electron `spawn EINVAL` on Windows, electron-builder winCodeSign extraction failures, and Inno Setup script parser errors — before landing on a clean, distributable `.exe` that a non-technical user can run with a double-click.
